# Vanilla chrome context

The full reference assembles the original 1.12.1 FrameXML geometry: a 1024-by-53 bar, four 256-by-43 body strips, a four-part 10-high XP border and two 128-by-128 gryphons. The resulting transparent canvas is 1216 by 128 because the gryphons extend outside the bar. It omits live buttons, micro-menu contents, bags, text and XP fill; it is a chrome study, not a game screenshot.

`compact7-no-xp.png` (300 by 43) and `compact7-xp.png` (300 by 53) are an adapted seven-slot study made entirely from those existing source pixels. Seven 36-unit slots use the native 6-unit pitch gap. Their left origins are 6, 48, 90, 132, 174, 216 and 258. This compact geometry is not the original Vanilla layout.

Pixel source: Gethe/wow-ui-textures, commit `e80e3278cc833c89e1f3fc79557b68315d750935`, `MAINMENUBAR/UI-MainMenuBar-Dwarf.PNG` and `MAINMENUBAR/UI-MainMenuBar-EndCap-Dwarf.PNG`. These are retained legacy sprites in a Dragonflight PTR snapshot, not a claim of byte-identical 1.12.1 files. The verified source geometry is MOUZU/Blizzard-WoW-Interface, commit `d162a4c0d198a4381b5b6573d975635ed7316702`, under `1.12.1/FrameXML/`.

Local `patch.MPQ` files are kept separately: its atlas has the menu quarter changed into additional ability placeholders, so it was not used for the full original-style chrome assembly. Its original-named gryphon and empty-slot assets are extracted as useful native references. Temporary `FRIZQT__.TTF` was extracted from the same archive for static preview typography only and is not retained here. To supply a locally available preview face to the gallery script, set `SDUI_PREVIEW_FONT` to that font file; otherwise it uses the system Arial fallback.

The unchanged sprite palette is aged silver/gray in the highlights, charcoal stone, and muted olive/brown inside the recesses. Warm copper/bronze Diablo assets would need their color moved toward neutral gray to match closely. A narrow aged-brass accent can remain as a distinct accent, but replacing the full native silver trim with orange bronze would change the family of the original bar.

All source crops, dimensions and URLs/commit pins are in `sources.json`. `assemble.py` is an inert archived assembly record, not an active generator. Its original `public-comparison/UI-MainMenuBar-Dwarf.PNG` and `public-comparison/UI-MainMenuBar-EndCap-Dwarf.PNG` inputs were temporary preparation files and are not retained in this repository; the pinned public source identifies them. The generated context and compact PNGs are retained. The original BLPs and public PNGs remain distinct from previews. Blizzard artwork and the native font retain their original ownership; public mirrors do not grant a new media license. These files are temporary proposal/context material and were not added to the runtime payload. No addon, Lua or game execution was used.
