# Thirty tally concepts

Open [the gallery](index.html), [all thirty](overview.png), or comparison sheets
[01–10](sheet-1.png), [11–20](sheet-2.png), [21–30](sheet-3.png).
Each card compares joined XP with the shorter action shell. Every tally
compartment shares the action bar's bottom silver edge as its top border,
without a gap, duplicate top rail, mounting tab or leg. The native sword,
gold quadrant and loot-pouch artwork stay the same in every design.

These are local static proposals. The current runtime provides a continuous
27-unit-high attached lower compartment and keeps the original gold pill
when detached.
The thirty colors, lower silhouettes and subdivisions have not been installed
as selectable skins. Deeper or decorative variants need final geometry after
selection. The left/right comparison shows XP attached/visible and XP
off/detached/unavailable; detached XP remains independently movable.

Real bundled action-bar, XP and character-window artwork is
composed with new geometric shapes. Runtime keeps the DEFAULT font; preview
labels use a local system face. Sample action slots are empty and numbers are
illustrative. The two cursor PNGs in `research/` are pinned previews from the
Blizzard texture mirror and do not replace native game textures.

Detailed source pins, crop/assembly information, Diablo-style source research,
permission limits and retail comparisons are in
[Tally-ARTWORK.md](../../../third_party/Tally-ARTWORK.md). Reproducible artwork
composition lives in [preview_tally_designs.py](../../../scripts/preview_tally_designs.py).
No proposal, source image or research file belongs in the runtime payload.
