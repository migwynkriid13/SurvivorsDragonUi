# Ability cooldown numbers

The seven action buttons retain their existing artwork, spacing, native cooldown swipes, click handlers, locked slots and shared layout scaling. An anonymous child frame on each button draws a centered DEFAULT-font countdown above its swipe, with a 14-pixel maximum, outline and black shadow. These labels inherit their button's scale, alpha and visibility.

The appearance is inspired by [Turtle Dragonflight's cooldown-number module](https://github.com/DustinChecketts/Turtle-Dragonflight/blob/b2c62e9095e1c859bff0209db09f4ff5b9884f5a/mods/cooldown-numbers.lua) and [time formatter](https://github.com/DustinChecketts/Turtle-Dragonflight/blob/b2c62e9095e1c859bff0209db09f4ff5b9884f5a/helpers.lua#L266-L282), by TheLinuxITGuy with Shagu's cooldown-number styling: white text, yellow below 10 seconds, red below 5 seconds, and rounded-up seconds or abbreviated minutes, hours and days. A native cooldown whose full duration is under two seconds has no number, while the final seconds of a longer cooldown remain visible.

This is an independent implementation inside `modules/bars/bars.lua`, with no imported upstream code, artwork, modules or dependencies. One updater reads `GetActionCooldown(ActionButton_GetPagedID(button))` at most every 0.1 seconds, with immediate refreshes for native cooldown and slot-change events. The seventh displayed button continues reading native slot 12. The same native getter supplies the stock [1.12.1 action-button cooldown swipe](https://github.com/MOUZU/Blizzard-WoW-Interface/blob/master/1.12.1/FrameXML/ActionButton.lua#L279-L282).

Each refresh rereads native start, duration and enabled state instead of retaining its own cooldown countdown. Missing, disabled, expired or unusable timing and empty/hidden buttons hide their labels. World leave/logout clear the numbers; world entry rereads current native values. The code does not modify native cooldowns, hook the global cooldown renderer, touch encounter debuff timers or persist gameplay state.

The **Cooldown numbers** checkbox in `/sdui` → **HUD** defaults on. It uses the existing `SurvivorsDragonUiDisplay` preference table, storing only the normalized boolean `cooldownNumbers`; missing or invalid values remain on. Clicking previews immediately and turning it off clears the labels and skips periodic native cooldown reads. Confirm alone saves; world leave/logout/reload discard drafts, and `/sdui reset` or **Addon defaults** restore on through the shared display reset. The editor is one row taller to keep all six HUD rows above its shared footer. No commands, assets or separate SavedVariables are added.

No local validation, syntax checks, tests, formatters, addon execution or game startups were run. GitHub Actions may check formatting, local dead code and TOC version metadata only. Those checks do not establish the modified client's cooldown timing, pause behavior, rendering or in-game compatibility.
